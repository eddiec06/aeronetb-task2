✈️ AeroNetB Task 2 Dashboard

A Student Project for Hybrid Database Management

📋 Project Overview

AeroNetB Task 2 Dashboard is a comprehensive web-based system designed as a university coursework project for managing suppliers, shipments, quality control, and IoT monitoring in an aerospace supply chain context.

The system demonstrates how a hybrid database architecture (SQL + MongoDB) can be effectively used to manage operational data and monitoring systems in a real-world scenario.

🎯 Key Features

  • Role-based authentication (Admin, Manager, Auditor)
  • Comprehensive dashboard with KPI cards
  • Supplier management and tracking
  • Order management with detailed modal views
  • Shipment tracking with status filtering
  • Quality control reporting system
  • IoT sensor monitoring and logging
  • Light/Dark mode theme toggle
  • Responsive design for all devices
  • Clean, student-friendly UI

🔌 API Endpoints

The system demonstrates integration with the following API endpoints:

GET /api/orders GET /api/suppliers GET /api/shipments GET /api/qc-reports GET /api/iot-logs

💾 Database Architecture

SQL Tables: orders, suppliers, shipments, qc_reports

MongoDB Collections: iot_logs, sensor_data

This hybrid approach demonstrates how relational data (orders, suppliers) can coexist with document-based data (IoT logs, sensor readings) in a single application.

🎨 Design Philosophy

The dashboard follows a clean, modern design approach suitable for a student coursework project. Key design principles include:

  • Light background with white cards for clarity
  • Rounded corners and consistent spacing
  • Grey accent colors for a professional appearance
  • Dark mode support for accessibility
  • Intuitive navigation with sidebar menu
  • Clear data visualization with status badges
